The maths. Every land triggers every Swarm, and each Yarok effect adds one more trigger, so a Swarm triggers 1 + Yaroks times per land. Each trigger makes one copy. This assumes you already control 20 or more Insects, so every trigger makes a Scute Swarm copy and not a 1/1 Insect token.
